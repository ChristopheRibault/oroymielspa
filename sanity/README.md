# Sanity Studio

This folder contains the Sanity Studio for Oro y Miel.

## Setup

1. Create a Sanity project in your Sanity account if needed.
2. Set these environment variables before running the studio:
   - `SANITY_STUDIO_PROJECT_ID`
   - `SANITY_STUDIO_DATASET`
   - `SANITY_STUDIO_API_VERSION`
3. Install dependencies from this folder.
4. Run `npm run dev` inside `sanity/`.

## Notes

The schema starts with four document types:

- `siteSettings`
- `homePage`
- `contactPage`
- `serviceCategory`
